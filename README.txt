КЕШБЭК — ЛОКАЛЬНОЕ ВЕБ-ПРИЛОЖЕНИЕ

Запуск:
1. Распакуйте архив.
2. Откройте index.html в браузере (Safari на iPhone или браузер на компьютере).
3. Добавляйте расходы, выбирайте банк и категорию. Рекомендация сравнивает активные ставки.

Данные:
- Приложение хранит данные в localStorage текущего браузера.
- Для резервной копии нажмите ↗ в верхней части приложения. Сохранится cashback-backup.json.
- Для восстановления нажмите ↙ и выберите JSON-файл резервной копии.
- CSV экспортирует расходы выбранного месяца.
- Не очищайте данные сайта/браузера, пока не сделаете резервную копию.

Ограничения:
- Полностью локально, сервер и интернет для работы не нужны.
- Ставки не подтверждаются банками и задаются вручную.
- Пока не реализованы MCC-коды, банковские лимиты, округление и условия начисления.
- Для разных браузеров/режимов открытия хранилище может быть отдельным. Резервное копирование рекомендуется регулярно.
